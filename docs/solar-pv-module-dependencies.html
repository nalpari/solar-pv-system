Dependency Graph · Internal Imports

모듈 의존 관계

저장소의 @/ · 상대경로 import 를 전부 모아 모듈 단위로 접은 그래프다. 진입점은 둘, 최종 싱크도 둘 — 클라이언트 쪽 app/types 와 서버 쪽 lib/qsp 가 각각 세 모듈의 의존을 받는다. 순환 의존은 하나도 없다.

Structure

싱크가 둘, 경계를 넘는 선은 하나

  • app/types/index.ts — page · components · utils 가 모두 의존하는 도메인 SSOT
  • lib/qsp/** — page · api · openapi 가 의존. envelopeSuccess/envelopeError 가 여기 있어서 라우트 전부가 붙는다
  • 클라이언트가 src/lib 를 건드리는 유일한 지점이 page.tsx → lib/qsp/schema 다 (그림의 SCHEMA 선). 타입만 가져가므로 런타임 번들에는 영향이 없다

Health

순환 의존 0건

  • 모든 forward edge 가 rank 를 따라 아래로만 흐른다 — 되돌아가는 선이 없다
  • 그래서 이 그래프에는 accent(코랄) 요소가 없다. 이 타입에서 accent 는 순환 표시 전용이다
  • 다만 트리는 아니다 — 부모가 둘 이상인 노드가 4개라 트리로는 그릴 수 없다
  • page.tsx 자체는 855줄 god-node 지만, 모듈 의존 구조는 건강하다는 게 이 그림의 결론이다
