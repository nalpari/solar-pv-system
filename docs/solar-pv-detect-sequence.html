지붕면 자동 감지

한 번의 POST 뒤에 업스트림 두 개가 순차로 붙는다 — Replicate SAM 이 건물 마스크를 뽑고, 그 마스크를 힌트로 붙인 프롬프트가 OpenRouter 로 간다. 응답이 돌아왔을 때 그것을 쓸지 버릴지는 클라이언트의 abortControllerRef 가 결정한다.

Race guard

응답보다 취소가 먼저일 수 있다

  • 새 요청이 시작되면 이전 controller.abort() 후 ref 를 교체한다
  • 돌아온 응답은 abortControllerRef.current !== controller 이면 조용히 버린다 — AbortError 도 alert 하지 않는다
  • finally 는 자기 controller 일 때만 ref 를 비우고, 취소된 경우엔 detectStatus 를 건드리지 않는다

Server gate

reason 이 세 갈래로 갈린다

  • ok — zod 통과 + 최저 신뢰도 ≥ 0.5
  • no_polygons — 모델이 0개 반환
  • low_confidence — 하나라도 0.5 미만이면 전체 차단 (일부만 빼면 합집합에 구멍이 생긴다)
  • confidence 는 서버 게이트 전용 — 클라이언트는 읽지 않는다

Fidelity ledger

  • SAM 실패 시 null 로 원본 단독 진행하는 폴백 분기
