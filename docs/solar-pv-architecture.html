Solar PV System

브라우저 하나가 모든 상태를 쥐고, 외부로 나가는 길은 단 두 갈래다 — Google Maps 로 직결되는 길과, src/proxy.ts 의 Origin 검증 + per-IP rate limit 을 통과해야만 열리는 BFF 길.

Trust boundary

경계는 한 파일에 모여 있다

  • src/proxy.ts matcher 가 qsp · musbi · detect-roof · image 네 갈래를 모두 덮는다
  • Origin 헤더가 있으면 ALLOWED_ORIGIN 과 정확히 일치해야 하고, 없으면 GET/HEAD 만 통과
  • 배포에서 ALLOWED_ORIGIN 미설정 = 모든 POST 403. standalone 은 0.0.0.0:3000 으로 바인드돼 폴백이 절대 맞지 않는다
  • rate limit 은 in-memory — 인스턴스가 늘면 한도가 인스턴스 수만큼 곱해진다

State ownership

상태는 전부 Home 이 쥔다

  • context 도, 상태 라이브러리도 없다 — useState 약 30개가 page.tsx 한 곳에
  • 자식에게 명령을 보낼 땐 증가하는 숫자(signal)를 내려보낸다 — 폴리곤의 진실은 CropPopup 캔버스에 있어서다
  • React Compiler 가 켜져 있어 파생값은 매 렌더 계산하고 수동 memo 를 붙이지 않는다
  • 저장소가 없다 — 새로고침하면 세션이 사라진다

Fidelity ledger

이 그림에서 뺀 것

  • /api/openapi · /reference — 경계 밖의 문서 sink. ENABLE_API_DOCS 로만 열린다
  • Home → 자식 컴포넌트 화살표 — 포함 관계로 이미 읽힌다
  • RoofEditToolbar · AiDetectControls · NoticePopup — CropPopup 하위 leaf UI
  • i18n.ts — 전 모듈이 쓰는 cross-cutting. 언어 전환 UI 는 미연결("ja" 고정)
  • zod 스키마 노드 — 라우트/클라이언트의 속성으로 흡수
